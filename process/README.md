# Word queue

For terms wanted before there is a source to capture — something remembered in
the car, a word needed for a job next week, a gap noticed while reading.

- `to-add/` — pending. One file per theme. Format is deliberately loose: the
  English term, then an example sentence for disambiguation, separated by `/`.
  A bare word without context produces a bad entry, because most English
  technical words have several unrelated Hebrew equivalents depending on trade.
- `done/` — processed. Kept rather than deleted so the origin of an entry stays
  traceable, and dated on the way in.

Where there **is** a source — a screenshot, a listing, a photo of a shelf label —
skip the queue entirely and use the `vocab-capture` skill. A source carries
register information that a bare word list cannot, and it is the better route.
